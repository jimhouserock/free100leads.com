# free100leads.com AI skill

A Claude Code / Claude AI skill for [Free100Leads](https://free100leads.com): filtering and claiming daily free B2B leads, and what the paid plans unlock.

See `SKILL.md` for the full walkthrough.

## Using this skill

Copy `SKILL.md` into a project's `.claude/skills/free100leads/` (or `.agents/skills/free100leads/`) directory so Claude can answer questions about how to use Free100Leads.
